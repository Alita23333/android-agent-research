## Adapter interfaces created

The stable Android-host contracts are in `zcode/adapter/AndroidToolContracts.kt`:

- `AndroidToolDefinition`
- `AndroidToolRequest`
- `AndroidToolResult`
- `AndroidToolError`
- `ArtifactRef`
- `AndroidToolCancellation`
- `MutableAndroidToolCancellation`
- `AndroidToolDispatcher`

Contract properties:

- Every request has a host request ID and tool ID.
- Arguments and metadata remain structured JSON.
- Results cannot be both successful and contain an error.
- Failed results must contain a structured error.
- Artifacts preserve ID, name, MIME type, URI, and size.
- Cancellation can be observed and can register process/tool callbacks.
- The Phase 4 Gateway can implement `AndroidToolDispatcher` without changing the ZCode carrier or local providers.

### ZCode tool mapping

`ZCodeToolMapping` defines the carrier-neutral mapping:

- Android definition → `name`, `description`, `inputSchema`, and metadata.
- ZCode call → request ID, tool name, arguments/input, session ID, and metadata.
- Android result → tool call ID, `isError`, text content, and full structured content.
- Structured errors and artifacts are retained in `structuredContent`.

This canonical representation is intentionally behind `ZCodeToolCarrier`. The production carrier may wrap the fields in its exact upstream message shape after that shape is verified from the supplied ZCode bundle.

### Android Local Tool Protocol mapping

`LocalToolProtocol` defines exact JSON-RPC 2.0 initialize and `tools/call` messages. It remains separate from ZCode Protocol.

Cancellation for protocol 1.0 is mapped as follows:

1. cancellation propagates from `AndroidToolCancellation` to the existing core cancellation signal;
2. `JsonRpcStdioProvider` terminates the provider process because protocol 1.0 has no cancellation notification;
3. the call returns structured `CANCELLED`;
4. a subsequent request starts a new provider process.

This fallback is covered by a real child-process unit test. A future cooperative protocol cancellation method can be added as a negotiated minor-version capability without changing `AndroidToolRequest` or `AndroidToolResult`.
